本报告汇总近期完成的三部分实证准备工作：一是地级市面板原始数据的异常值排查、口径对齐与关键指标构造；二是针对历史统计年鉴漏报造成的控制变量缺失机制检验与多重插补对比；三是双向固定效应基准模型与安慰剂检验估计结果。文末第四部分列出三个待确认的模型设定细节，供审阅把关并商定定稿方案。

# 一、原始数据异常排查与样本筛选

## （一）面板覆盖范围与有效分析样本界定

全量底表合并去重后共包含 285 个地级市在 2012 至 2023 年间的 3,420 个城市年度观测值。原始年鉴摘录表仅含 18 个基础统计列，经异常值清洗、行政区划变更对齐与外部地理距离匹配后，扩展为 56 列标准面板数据表，核心指标综合合格率达到 99.65%。剔除年内发生撤地设市调整的 42 个过渡观测值后，保留平衡面板样本 3,378 个观测值。

## （二）原始统计表三类异常值的清洗规则

逐列核查早期摘录底表时，共定位并修复三类数据质量问题。第一，部分财政支出字段混入电子表格公式报错字符串与单位换算错位，清洗程序按年度预算决算合理区间清空错误文本，并回查省级统计年鉴原表逐条补齐。第二，个别城市因重名县区汇总口径混淆导致常住人口突跳，核查组对照民政部行政区划代码表重新锁定市辖区与全域口径。第三，利用标准行政中心坐标统一重算各城市至省会城市的球面距离，消除了早期手工录入的经纬度笔误。表 1 报告了清洗前后主要指标的完备率对比。

# 二、基准回归模型设定与稳健性检验

实证模型在“城市—年份”双向固定效应框架下考察政务数字化转型对跨部门行政响应效率的影响，基准回归方程设定如下：

$$Y_{c,t} = \beta_1 \text{DigitalGov}_{c,t} + \rho Y_{c,t-1} + \mathbf{X}'_{c,t}\boldsymbol{\gamma} + \mu_c + \lambda_t + \varepsilon_{c,t}$$

其中被解释变量 $Y_{c,t}$ 为城市 $c$ 在第 $t$ 年的平均工单办结天数，核心解释变量 $\text{DigitalGov}_{c,t}$ 为政务服务数字化指数，$\mu_c$ 与 $\lambda_t$ 分别代表城市固定效应与年份固定效应，标准误聚类至地级市层面。为排除遗漏变量与缺失删失偏误，模型依次对比了整行删失、逆概率加权以及前置两期改革虚构时间点的安慰剂检验。估计结果见表 2。

# 三、待审阅确认的三个具体问题

围绕样本边界与标准误推断细节，以下三个问题需进一步商定定稿口径：

第一，副省级城市是否单列异质性子样本。由于 15 个副省级城市在财政自主权与政务系统建设周期上显著高于普通地级市，需确认正文主表是保留全部地级市并在附录展示剔除副省级城市结果，还是直接在主表中并列报告两类样本。

第二，动态面板滞后项的偏误校正方式。第 (2) 列同时纳入滞后一期被解释变量与城市固定效应，在时间跨度为 12 年的面板上可能存在轻微动态面板偏误，需确认是否在稳健性部分补充系统广义矩估计或纠偏固定效应估计量。

第三，聚类层级的敏感性汇报。目前标准误聚类在地级市层面（共 285 个聚类），考虑到同一省份内部政务平台建设往往同步推进，需确认是否统一改为在省份层面聚类并辅以野自助法推断检验。
