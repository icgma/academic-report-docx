PIPELINE ARCHITECTURE

拒绝“生成即交付”：三道自动化脚本门禁

Three Deterministic Quality Gates Before Delivery

每一次文档编译均自动串联文风扫描、表文实证数字对账与底层 OpenXML 结构断言，任何一项不达标即按行号精准阻断回报。

Every compilation chains context-aware prose linting, narrative-vs-table numerical reconciliation, and strict OpenXML schema assertions.

GATE 01 · PROSE Context-Aware

语境感知汇报文风门禁

Context-Aware Prose Gate

强制零第一/第二人称客观汇报视角（自动豁免双引号 “……” 与 > 引用块内的访谈原话），拦截生僻古语、AI 套话、句中英文括号路障与超 38 字长分句，严格校验“表上表题、图下图题”。

Enforces zero 1st/2nd-person narrative voice while exempting quoted interview/archival speech, blocks AI jargon and inline English brackets, caps unbroken CJK clauses at 38 chars, and checks caption placement.

python scripts/audit_report_prose.py report.md
GATE 02 · EMPIRICAL Anti-Hallucination

实证数字表文交叉对账门禁

Empirical Number Verification

自动提取每张表格的带符号系数、标准误与样本量 N，交叉核验正文引用句，精准捕获正负号抄反与小数移位；支持 --data-source 绑定统计脚本导出的 JSON/CSV 真值逐数对账。

Cross-checks narrative claims against cited tables to catch coefficient sign flips and digit transpositions, with optional --data-source results.json ground-truth reconciliation.

python scripts/verify_numbers.py report.md --data-source res.json
GATE 03 · OPENXML GB/T 7713.1

底层 OpenXML 版式断言门禁

OpenXML Typesetting Assertions

直接重写 document.xml、styles.xml 与 footer1.xml 并解包重验：断言全篇颜色集合恒等于 {#000000}、中西文字体严格分离为宋体与 Times New Roman、三线表磅值精确闭合。

Rewrites raw OpenXML parts and unpacks the resulting .docx to assert 100% #000000 black ink, exact SimSun + Times New Roman font separation, and 1.5pt / 0.75pt / 1.5pt Three-Line Tables.

python scripts/md_to_academic_docx.py report.md --verify

RELEASE v1.1.0 UPGRADES

面向真实科研工作流的六重工程鲁棒性

Six Production-Grade Robustness Upgrades in v1.1.0

针对多列回归宽表、质性访谈引文、既有杂乱 Word 改排、无 Pandoc 裸机环境与 Windows 文件占用锁等高频实战痛点逐一加固。

Hardened against wide regression tables, qualitative quotes, legacy Word restyling, Pandoc-free machines, and Windows file locks.

01 / QUOTE EXEMPTION & PROFILES

引语豁免与可插拔学科词库

Quote Exemption & Profiles

自动识别并豁免 “……” 与 > 块引用中的受访者原话与史料引文；词表外置至 configs/prose_rules.json，支持学科配置自由扩展。

Exempts direct interview/archival quotes inside quotation marks and blockquotes; externalizes lexical rules into pluggable JSON profiles.

02 / LANDSCAPE & CMIDRULE

宽表自动横向分节与双层跨列表头

Auto-Landscape & Spanned Headers

7 列及以上宽表自动切换至横向 A4 分节页并在表后切回纵向；表头首行写入 > 自动生成 w:gridSpan 跨列组表头与 0.5pt 栏目子线。

Wraps ≥7-column tables in dedicated Landscape A4 sections and merges 2-row grouped headers with partial 0.5pt cmidrule sub-borders.

03 / FIGURE NORMALIZATION

插图自适应限宽与 SVG 支持

Figure Engine & SVG Support

自动限宽超宽图片至 ≤ 14.5 cm，清零图片段首行缩进消除右偏，兼容 .png/.jpg/.svg，锁定 keepNext 防止图文跨页分离。

Clamps figure extents to ≤14.5 cm, zeroes first-line indent on image paragraphs, handles PNG/JPEG/SVG, and locks figures to captions below.

04 / DIRECT DOCX RESTYLE & LOCK SAFE

既有 .docx 一键重排与占用锁保护

Direct --restyle & Lock Fallback

传入 --restyle 直接清洗合作者发来的杂乱彩色 Word 文档；检测到 Word/WPS ~$ 占用锁时自动回退输出至 *_updated.docx。

Cleans messy existing .docx files directly via --restyle, and safely falls back to *_updated.docx when Word/WPS holds a file lock.

05 / EMPIRICAL NUMBER GATE

表文数字与 JSON 真值交叉核验

Empirical Number Cross-Check

自动扫描正文与引用表格的系数符号及高精度小数一致性，支持绑定 --data-source results.json 阻断手写填数错漏。

Detects sign contradictions and transposed digits between prose and tables, and reconciles every statistic against JSON/CSV outputs.

06 / ZERO-PANDOC NATIVE OMML

零 Pandoc 原生公式与三端矩阵 CI

Zero-Pandoc OMML & 3-OS CI

内置纯 Python 递归解析器将 LaTeX 分式、根式、求和积分直接编译为可编辑 Word <m:oMath> 公式；GitHub Actions 持续验证三端兼容性。

Compiles LaTeX equations directly into native Word <m:oMath> AST in pure Python without Pandoc, continuously tested on Ubuntu, macOS, and Windows.
